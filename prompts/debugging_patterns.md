# デバッグ・問題解決のためのプロンプトパターン

コードや数学的理解の問題を解決するためのプロンプトパターン集。

## コードのデバッグ

### パターン1: エラーメッセージの解析

```
以下のエラーが発生しました：
```
[エラーメッセージ全文]
```

コードは以下です：
```python
[問題のコード]
```

エラーの原因と修正方法を説明してください。
```

### パターン2: 予期しない結果

```
以下のコードを実行しましたが、期待と異なる結果が得られました。

コード：
```python
[コード]
```

期待した結果：[期待値]
実際の結果：[実際の値]

なぜこうなったのか、どう修正すべきか説明してください。
```

### パターン3: 数値的不安定性

```
以下の計算で数値的な問題（NaN、Inf、精度低下など）が発生しています。

```python
[問題のコード]
```

数値的に安定なバージョンに修正してください。
log-sum-exp trickなどのテクニックが適用可能か検討してください。
```

## 数学的理解のデバッグ

### パターン4: 計算結果の検証

```
[数式/計算]を手計算で行いました。
結果は[自分の結果]になりました。
これは正しいですか？もし間違っていれば、正しい計算過程を示してください。
```

**例:**
```
正規分布N(0,1)のFisher情報行列を計算しました。
結果は I = [[1, 0], [0, 1]] になりました。
これは正しいですか？もし間違っていれば、正しい計算過程を示してください。
```

### パターン5: 公式の適用確認

```
[公式名]を[具体的な状況]に適用しようとしています。
私の適用方法：
[自分の計算/コード]

この適用は正しいですか？公式の前提条件を満たしていますか？
```

### パターン6: 直感との不一致

```
[概念/結果]について、私の直感と数学的結果が一致しません。

私の直感：[直感的な予想]
数学的結果：[実際の結果]

どちらが正しいのでしょうか？なぜこのような違いが生じるのですか？
```

## パフォーマンス問題

### パターン7: 計算速度の改善

```
以下のコードが遅いです（現在の実行時間：約[X]秒）。

```python
[遅いコード]
```

高速化する方法を提案してください。
目標実行時間：[目標時間]
使用可能なリソース：[CPU/GPU、メモリなど]
```

### パターン8: メモリ使用量の削減

```
以下のコードがメモリを大量に消費します。

```python
[メモリ消費の大きいコード]
```

データサイズ：N = [サイズ]
利用可能メモリ：[メモリ量]

メモリ効率を改善する方法を提案してください。
```

## 概念理解の問題

### パターン9: 混乱の解消

```
[概念A]と[概念B]の違いがよくわかりません。
特に以下の点で混乱しています：
- [混乱ポイント1]
- [混乱ポイント2]

明確に区別できるよう説明してください。
```

**例:**
```
「自然パラメータ」と「期待値パラメータ」の違いがよくわかりません。
特に以下の点で混乱しています：
- どちらをいつ使うべきか
- 変換公式の導出
- Fisher情報行列との関係

明確に区別できるよう説明してください。
```

### パターン10: 前提条件の確認

```
[定理/公式]を使おうとしていますが、自分の状況で適用できるか不安です。

私の状況：
- [条件1]
- [条件2]

定理の前提条件をすべて列挙し、私の状況で満たされているか確認してください。
```

## 実装の検証

### パターン11: 単体テストの作成

```
以下の関数の正しさを検証するテストを書いてください。

```python
[関数コード]
```

特に以下のケースをテストしてください：
- 基本的なケース
- エッジケース
- 既知の解析解との比較
```

### パターン12: 数値微分との比較

```
以下の解析的な勾配計算が正しいか、数値微分と比較して検証してください。

```python
[勾配計算のコード]
```

相対誤差が[許容誤差]以下であることを確認してください。
```

### パターン13: 既知結果との比較

```
[概念/計算]を実装しました。
正しく実装できているか、以下の既知の結果と比較して検証してください：

- [既知の結果1]
- [既知の結果2]

```python
[実装コード]
```
```

## 問題の切り分け

### パターン14: 最小再現例の作成

```
複雑なコードで問題が発生しています。
問題を再現する最小限のコードを作成するのを手伝ってください。

元のコード（長い）：
[省略可能なコードの概要]

エラー/問題：
[問題の説明]
```

### パターン15: 段階的デバッグ

```
以下のコードが正しく動作しません。
段階的にデバッグを進めるため、各ステップで中間結果を確認するコードを追加してください。

```python
[問題のコード]
```
```

## ベストプラクティス

1. **具体的に説明**: 「動かない」ではなく、何がどう動かないか具体的に
2. **コード全体を共有**: 関連するインポート文やデータ定義も含める
3. **期待値を明示**: 何を期待していたかを明確に
4. **試したことを報告**: すでに試した解決策を伝える
5. **環境情報を含める**: Python/ライブラリのバージョン、OS等
6. **簡潔に**: 問題に無関係なコードは省略
