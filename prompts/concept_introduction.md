# 概念導入のためのプロンプトパターン

情報幾何の新しい概念を学ぶ際に有効なプロンプトパターン集。

## 基本パターン

### パターン1: 既知概念からの橋渡し

```
[概念名]を説明してください。
私は以下の背景知識を持っています：
- [既知の概念1]
- [既知の概念2]

これらの既知概念との対応関係を明確にしながら説明してください。
```

**例:**
```
リーマン計量を説明してください。
私は以下の背景知識を持っています：
- 線形代数の内積と計量
- Fisher情報行列
- KLダイバージェンス

これらの既知概念との対応関係を明確にしながら説明してください。
```

### パターン2: 具体例先行

```
[概念名]を、[具体的な確率分布]を例に説明してください。
まず具体例から始めて、その後に一般的な定義を示してください。
```

**例:**
```
接ベクトルと接空間の概念を、正規分布N(μ, σ²)のパラメータ空間を例に説明してください。
まず具体例から始めて、その後に一般的な定義を示してください。
```

### パターン3: 直感→定義→応用

```
[概念名]について以下の順序で説明してください：
1. 直感的な理解（図や身近な例を用いて）
2. 数学的定義
3. 情報幾何での応用場面
```

## 高度なパターン

### パターン4: 異なる視点からの理解

```
[概念名]を以下の3つの視点から説明してください：
1. 幾何学的視点
2. 統計学的視点
3. 最適化の視点（機械学習への応用）
```

### パターン5: 比較による理解

```
[概念A]と[概念B]の違いと関係を説明してください。
具体的な計算例を含めてください。
```

**例:**
```
KLダイバージェンスとFisher-Rao距離の違いと関係を説明してください。
正規分布の具体的な計算例を含めてください。
```

### パターン6: 導出過程の理解

```
[公式/定理]の導出過程を、途中の計算を省略せずに示してください。
各ステップの直感的な意味も説明してください。
```

## 確認・深化のためのパターン

### パターン7: 理解度チェック

```
私の理解を確認してください：
[自分の理解を文章で書く]

この理解は正しいですか？誤りや不足があれば指摘してください。
```

### パターン8: 反例の要求

```
[概念/定理]が成り立たない場合の例を示してください。
どの条件が満たされないと成り立たないのかを説明してください。
```

### パターン9: 連続的な深化

```
[基本概念]は理解できました。
次に学ぶべき発展的な概念は何ですか？
それぞれの概念間の依存関係も教えてください。
```

## 研究経験を活かすパターン

### パターン10: カルマンフィルタとの接続

```
[情報幾何の概念]とカルマンフィルタの関係を説明してください。
- カルマンゲインの情報幾何的意味
- 状態更新の幾何学的解釈
- 共分散行列とFisher情報行列の関係
```

### パターン11: ベイズ推定との接続

```
[情報幾何の概念]をベイズ推定の文脈で説明してください。
- 事前分布と事後分布の幾何学的関係
- 共役事前分布の情報幾何的意味
- 情報ゲインとKLダイバージェンスの関係
```

## 注意点

1. **段階的に質問する**: 一度に多くの概念を質問しない
2. **自分の理解を示す**: 完全に白紙状態からの質問より、自分の理解を示した方が効果的
3. **具体例を求める**: 抽象的な説明だけでなく、必ず具体例を求める
4. **可視化を求める**: Pythonコードによる可視化を積極的に求める
5. **フォローアップする**: 理解できなかった点は遠慮なく再質問する
