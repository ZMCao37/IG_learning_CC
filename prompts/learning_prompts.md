# 情報幾何学習で有効だったプロンプト集

## 背景設定プロンプト（最初に使用）

```
私は情報幾何を学習中の研究者です。以下の背景があります：

【数学的背景】
- 線形代数、微積分は理解している
- 微分幾何は初学者（多様体、接ベクトル等は概念レベル）
- 確率・統計の基礎はある

【研究での関連経験】
- ベイズ推定、階層ベイズモデルの実装経験あり
- KLダイバージェンスを情報利得の計算に使用した経験あり
- カルマンフィルタ（EKF含む）の実装経験あり
- 期待効用最大化モデルの構築経験あり

【学習目標】
- 甘利俊一「情報幾何学の基礎」を読み進める
- 各概念の可視化コードを作成しGitHubで管理する
- 将来的に機械学習の最新研究を読み解く基礎を作る
```

## 概念理解プロンプト

### 新しい概念の導入
```
情報幾何の「[概念名]」について、以下の形式で説明してください：

1. 直感的な説明（図をイメージしながら）
2. 私の既知概念（KLダイバージェンス、カルマンフィルタ等）との対応
3. 正規分布を例にした具体的計算
4. Pythonでの可視化コード
```

### 計算の確認
```
正規分布 N(μ, σ²) に対して [計算内容] を計算してください。
途中式を省略せず、各ステップの意味も説明してください。
```

### 概念間の関係
```
情報幾何において「[概念A]」と「[概念B]」の関係を説明してください。
特に、私のカルマンフィルタ/ベイズ推定の経験と関連付けて説明してもらえると助かります。
```

## 可視化プロンプト

### 新しい可視化の作成
```
[概念] を可視化するPythonコードを書いてください。
要件：
- matplotlib使用
- 正規分布を例に
- 日本語コメント付き
- 既存の chapters/chXX_xxx/ 形式に合わせる
```

### インタラクティブ可視化
```
[概念] をインタラクティブに操作できるHTML/Plotlyダッシュボードを作成してください。
パラメータ（μ, σ等）をスライダーで変更できるようにしてください。
```

## デバッグ・疑問解決プロンプト

### 教科書の記述確認
```
甘利先生の教科書§X.X（p.XX）に「[引用]」とありますが、これは私の理解「[自分の理解]」と合っていますか？
```

### 計算結果の検証
```
以下のコードで [計算] を実装しましたが、結果が教科書と異なります。
どこに問題があるか確認してください。

[コード]
```
