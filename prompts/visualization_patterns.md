# 可視化のためのプロンプトパターン

情報幾何の概念を可視化するためのプロンプトパターン集。

## 基本的な可視化リクエスト

### パターン1: 概念の可視化

```
[概念名]を可視化するPythonコードを書いてください。
matplotlib/plotlyを使用し、以下を含めてください：
- グラフの軸ラベルとタイトル
- 凡例（必要な場合）
- 適切なカラーマップ
- グリッド線
```

**例:**
```
Fisher計量による「単位円」を、パラメータ空間の異なる点で可視化する
Pythonコードを書いてください。
σが小さい点とσが大きい点での楕円の違いがわかるようにしてください。
```

### パターン2: 比較可視化

```
[概念A]と[概念B]を並べて比較する可視化コードを書いてください。
サブプロットを使用し、両者の違いが明確になるようにしてください。
```

**例:**
```
KLダイバージェンスの等高線と、その2次近似（Fisher計量）の等高線を
並べて比較する可視化コードを書いてください。
参照点からの距離が増えると近似がどう変わるか示してください。
```

### パターン3: アニメーション

```
[プロセス/変化]をアニメーションで可視化するコードを書いてください。
以下の要件を満たしてください：
- matplotlib.animationを使用
- フレーム間の遷移が滑らか
- 保存可能（GIF/MP4）
```

## 情報幾何特有の可視化

### パターン4: パラメータ空間と分布空間の対応

```
パラメータ空間（μ-σ平面）と対応する確率分布を同時に可視化する
コードを書いてください。
- 左図：パラメータ空間での点/曲線
- 右図：対応する確率密度関数
```

### パターン5: Fisher計量楕円

```
統計多様体上のFisher計量を楕円で可視化するコードを書いてください。
以下を含めてください：
- 複数の点での楕円
- 楕円のサイズがFisher情報量の逆数に比例することの説明
- σが小さい領域で楕円が小さくなることの可視化
```

### パターン6: 測地線

```
[統計多様体]上の測地線を可視化するコードを書いてください。
- 始点と終点を指定可能
- パラメータ空間での測地線
- 対応する分布の変化（オプション）
```

### パターン7: KL等高線

```
KLダイバージェンスの等高線図を描くコードを書いてください。
- 参照点の指定
- 複数のダイバージェンスレベルの表示
- forward/reverse KLの選択
```

## インタラクティブ可視化

### パターン8: Plotlyによるインタラクティブ図

```
[概念]をPlotlyでインタラクティブに可視化するコードを書いてください。
以下の機能を含めてください：
- ズーム/パン
- ホバーで情報表示
- パラメータをスライダーで変更可能
```

### パターン9: Jupyter Widget

```
ipywidgetsを使って、パラメータを動的に変更できる
可視化を作成してください。
スライダーで[パラメータ]を変更すると、グラフがリアルタイムで更新されるようにしてください。
```

## 高度な可視化

### パターン10: 3D可視化

```
[概念]を3D表面として可視化するコードを書いてください。
- mpl_toolkits.mplot3dを使用
- 視点の回転が可能
- カラーマップで高さ/値を表現
```

**例:**
```
正規分布の多様体上でのKLダイバージェンスを3D表面として
可視化するコードを書いてください。
z軸をKL値、x軸をμ、y軸をσとしてください。
```

### パターン11: ベクトル場

```
[ベクトル場]を矢印プロットで可視化するコードを書いてください。
- 勾配場
- 自然勾配場
- 両者の比較
```

### パターン12: 多様体の「曲がり」

```
統計多様体の曲率を可視化するコードを書いてください。
平坦でないことを直感的に理解できる図を作成してください。
```

## 出力形式

### パターン13: 論文品質の図

```
論文に掲載できる品質の図を作成するコードを書いてください。
以下の設定を含めてください：
- 高解像度（dpi=300）
- フォントサイズの適切な設定
- PDFまたはSVG形式での保存
- LaTeXスタイルの数式
```

### パターン14: プレゼンテーション用

```
スライド発表に適した図を作成するコードを書いてください。
- 大きなフォントサイズ
- シンプルで見やすいデザイン
- 濃い色使い
```

## トラブルシューティング

### 図が表示されない場合

```
matplotlibの図が表示されません。以下の状況を考慮してください：
- Jupyter Notebook環境
- %matplotlib inline は設定済み
- plt.show() は呼び出している

問題を診断し、解決策を提示してください。
```

### 性能問題

```
可視化コードが遅いです。以下の条件で高速化してください：
- データ点数：N個
- リアルタイム更新が必要
- NumPyのベクトル化を活用
```

## ベストプラクティス

1. **再利用可能な関数化**: 繰り返し使う可視化は関数にまとめる
2. **一貫したスタイル**: プロジェクト全体で統一されたスタイルを使用
3. **説明的なタイトル**: 図が何を示しているか一目でわかるように
4. **適切な色使い**: カラーユニバーサルデザインに配慮
5. **軸の単位**: 物理的な意味がある場合は単位を明記
